- **Frontend:** React · TypeScript · JavaScript · PWA · Responsive web arayüzleri

- **Güvenlik:** Rate limiting · Güvenlik başlıkları · Kullanıcı/veri sahipliği kontrolleri · Default-deny politika yaklaşımı · Güvenli dosya yükleme
